# IIT Guwahati Library Digital Token System

Product Requirements Document (PRD) proposing the digitization of IIT Guwahati Library's bag deposit process through integration with the OneStop app.

## Problem

The existing physical token system causes long queues, token loss fines, retrieval delays, and operational inefficiencies for both students and library staff.

## Solution

Designed a QR-based digital token system enabling students to deposit and retrieve bags through the OneStop app while providing guards with a real-time verification dashboard.

## Key Work

* Conducted user research with 140+ survey responses
* Identified student and staff pain points
* Defined product requirements and user flows
* Designed QR-based deposit and retrieval workflow
* Established success metrics and technical requirements
